# Garimpo Online — versão limpa

IMPORTANTE: não cole código Python dentro de `admin.html`. O arquivo `admin.html` deve conter somente o HTML/JavaScript fornecido nesta pasta.

1. Configure `config.js` com a URL do Supabase e a chave publicável.
2. No Supabase, crie um usuário em Authentication > Users.
3. Crie um bucket público chamado `product-images`.
4. Execute `supabase.sql`.
5. Publique os arquivos em GitHub Pages/Vercel/Netlify.

O visitante não precisa de login. Somente você usa `admin.html`.
